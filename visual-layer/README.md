# Nori Holographic Voice Layer

A standalone, mobile-first visual prototype inspired by the cyan holographic rings in the user's JARVIS references.

## What it does
- Procedurally draws irregular oscillating contours, particle grain, radial vibration lines, segmented arcs, echo ripples, and an inner wire mesh.
- Includes visual state toggles for standby, speaking, and listening.
- Uses no external image assets, libraries, microphone access, API keys, or network calls.

## Important limitation
This page cannot inject itself into the ChatGPT Android app, modify ChatGPT's native voice interface, or access this conversation's live audio. The speaking/listening buttons demonstrate animation states only. A genuine live voice-reactive layer would require a supported integration that exposes audio and cannot be added from within a ChatGPT conversation alone.

## Run
Open `index.html` in a modern browser. GitHub Pages may be enabled in repository settings to host it as a website.
